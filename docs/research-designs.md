# 研究设计模板

九类插件提供可运行的交互流程。`examples/*-research.html` 包含参与者信息、AI 任务、任务评价及数据下载。研究者可在这些 timeline 中加入自己的条件分配、量表、材料和结束说明。

| 功能 | 可以研究的问题 | 可设置的条件 | 可使用的数据 |
| --- | --- | --- | --- |
| 对话 | 建议表达和身份呈现怎样影响判断 | 助手标签、系统指令、轮数、输出长度 | 逐轮消息、输入时间、调用结果 |
| 追问访谈 | 固定提纲和自适应追问怎样改变信息丰富度 | 回放问题、实时追问、最大轮数 | 问题顺序、回答、追问和等待时间 |
| 结构化问卷 | 固定题项和个性化题项怎样影响回答 | 固定问题、生成问题、反馈开关 | 实际呈现题目、作答、结构校验结果 |
| 个性化反馈 | 反馈内容与呈现延迟怎样影响下一项任务 | 固定或生成反馈、呈现延迟、身份标签 | 完整输出、实际呈现和后续表现 |
| JAS 建议采纳 | 判断修订是否随建议来源或解释改变 | 固定或生成建议、来源标签、正确答案 | 初始判断、建议、最终判断、采纳及误差指标 |
| 多方案生成 | 提供多个方案是否改变选择和创造性表现 | 方案数、生成参数、固定材料 | 每个方案、选择、生成调用 |
| 共同创作 | AI 建议怎样改变人的修订行为 | 初始草稿、角色指令、轮数 | 原始回复、参与者修订和版本记录 |
| 学习与迁移 | AI 辅助学习的表现能否延续到独立测验 | 辅导指令、学习轮数、迁移问题 | 学习对话、撤除 AI 后的独立回答 |
| 多代理讨论 | 多个角色的意见和顺序怎样影响决策 | 角色指令、角色客户端、固定或随机顺序 | 实际发言顺序、角色消息、调用记录 |

## 可组合的研究流程

**内容与身份分开操纵。** 保存同一批材料，通过不同的 `labels.assistant` 和 `condition` 呈现。`delivery.mode = 'replay'` 保持内容相同；数据同时保存研究条件和实际来源。涉及身份遮蔽的研究由研究者准备相应说明与结束告知。

**实时互动与配对材料。** 先运行实时组并保存 jsPsych 数据，再用 `createYokedDelivery(sourceParticipant, rows)` 为配对参与者创建材料。记录配对关系，决定如何处理源参与者中断或材料不足；插件不会用未声明的模型补齐材料。

**先离线生成，再进行材料审核。** `pregenerateMaterials` 输出可序列化材料。研究者审核内容、冻结条件及材料，再用 `pregenerated` 或 `replay` 呈现。生成过程的耗时与参与者实验耗时分别分析。

**辅导撤除与迁移。** 在 `AILearningPlugin` 中设置迁移问题；迁移阶段关闭 AI 输入与重新生成。也可以在它之后接官方插件，完成有正确答案的测验、延迟测验或新的刺激任务。

**互动策略与跨任务变化。** 每个参与者创建 `ResearchSession`，通过 `memory_key` 决定哪些任务共享历史。比较有历史、无历史及不同角色的条件时明确使用不同键，避免条件间意外共享信息。

## 写入实验方案的项目

- 冻结插件、jsPsych、模型配置、系统指令、材料和失败策略；模型切换由研究代码明确配置。
- 保存条件分配、实际输出、重试、等待时间与呈现时间。AI 服务耗时不直接当作参与者反应时。
- 先确定输出截断、暂停、提前结束、请求失败和回放耗尽的处理规则。
- 新生成问卷题项需要单独检查测量性质；插件的结构校验只检查格式。
- JAS 初始判断等于建议值时，采纳比例分母为零，数据返回 `null`。
- 模型生成具有变化性。固定 seed 控制本包内的随机顺序；固定材料回放可用于逐字相同的呈现。

这些模板提供研究实现方式，效应方向、测量效度和样本量由具体研究确定。
